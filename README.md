# 課程影片網站

公開網址：**https://novel931008-bit.github.io/course-videos/**

GitHub 儲存庫：https://github.com/novel931008-bit/course-videos

網站放在 GitHub Pages（免費），不需要開著你的電腦，大家隨時都能看。
只有登入你 GitHub 帳號的電腦能發布更新，其他人只能瀏覽。

---

## 平常怎麼更新（每次上完課）

1. 雙擊這個資料夾裡的 **`編輯課程.bat`**，瀏覽器會打開「課程編輯器」。
   （會同時出現一個黑色視窗，編輯時不要關掉它。）
2. 把 YouTube 影片連結貼到「快速新增」。
   影片標題是「9/9 生理學：單元名稱」這種格式時，日期、科別、單元會自動填好。
3. 補上老師（可留空），確認內容沒問題。
4. 按右下角 **「儲存並發布到網站」**，大約 1 分鐘後網站就會更新。
5. 按「結束編輯器」，或直接關掉黑色視窗。

其他操作：

- 直接在表格裡修改文字、日期或連結。
- 「刪除」可以移除一列；↑ ↓ 可以調整**同一天**課程的先後順序（儲存時會自動依日期排序）。
- 影片還沒上傳的課，連結可以先留空，網站會顯示「影片尚未上傳」。
- 「預覽網站」可以先在自己電腦上看發布後的樣子。

## 注意事項

- YouTube 影片請設成 **「公開」或「不公開」**。設成「私人」的影片其他人看不到，編輯器會用紅字提醒。
- 網站是公開網址，知道網址的人都能看。目前已設定不讓 Google 等搜尋引擎收錄；
  如果希望能被搜尋到，刪掉 `docs/index.html` 裡含有 `robots` 的那一行。
- 分享網址時可以帶篩選條件，例如 `網址/?subject=生理學` 只會顯示生理學。

## 在另一台電腦編輯

1. 安裝 [Git](https://git-scm.com/download/win) 和 [Python 3](https://www.python.org/downloads/)（安裝時勾選「Add python.exe to PATH」）。
2. 下載這個專案：

   ```
   git clone https://github.com/novel931008-bit/course-videos.git
   ```

3. 雙擊 `編輯課程.bat`。第一次發布時會跳出 GitHub 登入視窗，登入即可。

編輯器每次啟動都會先從 GitHub 取得最新資料，所以在不同電腦輪流編輯也不會互相覆蓋。

## 資料夾內容

| 路徑 | 說明 |
| --- | --- |
| `docs/` | 公開網站（GitHub Pages 發布的就是這個資料夾） |
| `docs/courses.json` | 課程資料（由編輯器自動修改） |
| `docs/index.html`、`docs/app.js` | 網頁本身 |
| `tools/` | 本機編輯器，不會出現在網站上 |
| `編輯課程.bat` | 啟動編輯器 |

## 常見問題

- **發布後網站沒有變化**：等 1–2 分鐘再重新整理頁面（手機瀏覽器可能要多重新整理一次）。
- **發布失敗**：展開編輯器下方的「發布紀錄」查看原因。常見原因是沒有網路，或 GitHub 登入過期（再按一次發布，依照跳出的視窗重新登入）。
- **雙擊 `編輯課程.bat` 後視窗一閃就關掉**：通常是沒有安裝 Python 3，或安裝時沒有勾選「Add to PATH」。
- **編輯器網頁顯示「無法連線到編輯器」**：黑色視窗被關掉了，重新雙擊 `編輯課程.bat` 即可。
